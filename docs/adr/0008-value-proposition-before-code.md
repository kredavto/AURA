# ADR-0008: Value Proposition Before Active Code

## Status

Accepted

## Context

AURA is technically ambitious. The project risk is not only implementation difficulty; it is also the risk of building a strong local AI system that users do not value enough to adopt or pay for.

## Decision

AURA will complete a value proposition validation stage before active MVP code development.

Architecture work may continue in Sprint 0, but implementation must not expand into full product build until target segment, problem urgency, willingness to pay, and MVP scope assumptions have been tested with potential users.

## Consequences

- `Repository v0.3` is dedicated to value proposition validation.
- Implementation tasks must remain constrained until validation findings are recorded.
- MVP scope may be reduced or redirected based on user evidence.
- Product documents must mark unvalidated assumptions clearly.
